# SupeRR Selector Season 2 Dashboard

This Streamlit dashboard displays the supplied reference ranking CSV files without recalculating or reordering the rankings.

## Files
- `app.py` — dashboard
- `top_10_batters.csv` — reference batter rankings
- `top_10_bowlers.csv` — reference bowler rankings
- `methodology_report.pdf` — original methodology report
- `requirements.txt` — app dependencies

## Run
`streamlit run app.py`
